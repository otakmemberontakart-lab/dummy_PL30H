=========================================================
  PROTOKOL LANGSING 30 HARI
  README — CARA MEMBUKA FILE KIT (ZIP)
=========================================================

Terima kasih sudah membeli paket ini! 🙏

Semua materi kamu ada di dalam 1 file ZIP, isinya:

  1. Protokol Langsing 30 Hari.html        (Ebook utama)
  2. Kit 1 - Kalkulator Suite.html         (TDEE, macros, cheat meal)
  3. Kit 2 - Meal System.html              (Meal plan, database makanan, resep, grocery list)
  4. Kit 3 - Training & Progress Hub.html  (Workout, tracker berat & habit)
  5. Kit 4 - Survival Guide.html           (Kondangan, warteg, traveling, craving)

Semua file ini adalah HALAMAN WEB (HTML) yang jalan LANGSUNG di
HP/laptop kamu — TIDAK perlu internet setelah dibuka, dan TIDAK
perlu diinstal seperti aplikasi biasa. Kamu tinggal membukanya
lewat browser (Chrome/Safari/Edge).

Progress, checklist, dan hasil kalkulator akan otomatis
tersimpan di browser yang kamu pakai untuk membukanya — jadi
usahakan selalu buka dengan cara & browser yang SAMA setiap
kali, supaya progress-mu tidak hilang.

Silakan langsung lompat ke bagian sesuai perangkatmu:

  A. PC / LAPTOP (Windows & Mac)
  B. ANDROID
  C. iPHONE / iPAD (iOS)


=========================================================
  A. PC / LAPTOP (Windows & Mac)
=========================================================

Ini perangkat paling mudah, dijamin lancar.

1. Download file ZIP yang dikirimkan.
2. Klik kanan file ZIP → pilih "Extract All" (Windows) atau
   double-click filenya (Mac) untuk mengekstrak/membongkar isinya.
   Simpan hasil ekstrak di folder yang mudah kamu temukan lagi,
   misalnya folder "Protokol Langsing 30 Hari" di Desktop.
3. Buka folder hasil ekstrak tadi.
4. Double-click salah satu file .html (misalnya
   "Protokol Langsing 30 Hari.html") — file akan otomatis
   terbuka di browser (Chrome/Edge/Firefox/Safari).
5. Selesai! Untuk buka kit lainnya, ulangi langkah 4 dengan
   file yang berbeda.

Tips: simpan folder ini di tempat tetap (jangan di-pindah2 atau
dihapus), dan selalu buka dengan browser yang sama supaya
checklist & hasil kalkulator tidak hilang.


=========================================================
  B. ANDROID (HP/Tablet)
=========================================================

1. Download file ZIP-nya (biasanya otomatis masuk ke folder
   "Download").
2. Buka aplikasi "Files" / "File Manager" / "Pengelola File"
   bawaan HP kamu.
3. Cari file ZIP di folder Download, lalu tap file tersebut.
   Akan muncul pilihan "Extract" / "Ekstrak" — tap itu untuk
   membongkar isinya jadi 1 folder.
4. Masuk ke folder hasil ekstrak tadi, kamu akan lihat 5 file
   .html di dalamnya.
5. Tap salah satu file .html → pilih "Buka dengan" (Open with)
   → pilih Chrome (disarankan pakai Chrome).
6. File akan terbuka seperti halaman web biasa. Selesai!

Catatan: kalau HP kamu tidak punya fitur "Extract" bawaan,
install aplikasi ekstrak ZIP gratis dari Play Store (misalnya
"ZArchiver" atau "RAR"), baru ulangi dari langkah 3.

Selalu buka dari lokasi folder yang sama & pakai Chrome, supaya
checklist/kalkulator tersimpan dengan baik.


=========================================================
  C. iPHONE / iPAD (iOS)
=========================================================

PENTING: di iPhone/iPad, membuka file HTML lokal memang punya
kendala khusus — kalau dibuka dengan cara yang salah, halaman
bisa muncul berantakan, JavaScript-nya tidak jalan, atau
checklist & hasil kalkulator tidak tersimpan. Ini bukan file-nya
yang rusak, tapi karena Safari punya batasan untuk file yang
dibuka langsung dari aplikasi Files. Ikuti langkah di bawah ini
supaya semua fitur (kalkulator, checklist, tracker) berfungsi
normal.

LANGKAH 1 — Ekstrak ZIP-nya
1. Download file ZIP (lewat Safari, atau simpan dari WhatsApp/
   Email ke "Save to Files").
2. Buka aplikasi "Files" bawaan iPhone.
3. Cari file ZIP-nya (biasanya di folder "Downloads" atau
   "On My iPhone"), lalu tap file tersebut sekali.
4. iPhone akan otomatis membongkar/extract ZIP jadi 1 folder
   berisi 5 file .html.

LANGKAH 2 — Download aplikasi pembaca HTML lokal (gratis)
Karena Safari sering gagal menjalankan file HTML lokal dengan
sempurna, gunakan aplikasi khusus untuk membuka file HTML dari
Files, contohnya:

   • "Html Preview" (gratis, tanpa langganan, khusus untuk
     membuka file HTML lokal dari app Files di iPhone/iPad), atau
   • "Documents by Readdle" (gratis, file manager + browser
     bawaan yang bisa membuka file HTML lokal dengan baik)

Cari salah satu nama aplikasi di atas lewat App Store, install
(gratis), lalu buka aplikasinya.

LANGKAH 3 — Buka file kit dari aplikasi tersebut
1. Di dalam aplikasi (Html Preview / Documents by Readdle),
   cari & buka folder hasil ekstrak di Langkah 1 (biasanya ada
   akses ke "Files" / "On My iPhone" dari dalam aplikasi ini).
2. Tap salah satu file .html untuk membukanya.
3. Halaman akan tampil normal, lengkap dengan kalkulator dan
   checklist yang bisa dicentang.

CATATAN PENTING UNTUK iOS:
- Selalu buka file dari APLIKASI & FOLDER yang SAMA setiap kali.
  Kalau kamu buka lewat cara berbeda (misalnya kadang lewat
  Safari, kadang lewat app lain), progress/checklist bisa
  dianggap "halaman baru" dan datamu tidak akan muncul lagi.
- Jangan buka file HTML ini lewat preview bawaan WhatsApp/Email
  (ikon mata "Quick Look") — biasanya cuma menampilkan pratinjau
  statis, tombol dan kalkulatornya tidak akan berfungsi. Selalu
  pindahkan dulu ke Files, ekstrak, baru buka lewat aplikasi di
  Langkah 2.


=========================================================
  TROUBLESHOOTING (Kalau Ada Kendala)
=========================================================

❓ Halaman tampil polos/berantakan tanpa warna & tombol?
   → Biasanya kamu belum ekstrak ZIP-nya, atau file-nya dibuka
     lewat preview instan (Quick Look) bukan lewat browser/app
     yang disarankan. Ikuti ulang langkah ekstrak di atas.

❓ Progress/checklist hilang setiap kali dibuka lagi?
   → Pastikan kamu selalu membuka file dari lokasi folder &
     aplikasi/browser yang SAMA setiap kali. Jangan pindahkan
     folder hasil ekstrak setelah mulai dipakai.

❓ Perlu koneksi internet?
   → Tidak wajib. Semua kalkulator & fitur utama jalan offline.
     Koneksi hanya dibutuhkan sekali di awal untuk memuat huruf
     (font) — kalau internet mati, halaman tetap bisa dipakai
     hanya dengan huruf standar bawaan perangkat.
